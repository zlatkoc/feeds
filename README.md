# feeds

RSS feeds generated by a self-hosted [Hermes Agent](https://github.com/NousResearch/hermes-agent).
Each `*.xml` file in this repo is one RSS 2.0 feed. The agent adds new feed files and
updates existing ones; every change is committed and pushed automatically, so the
history here is the history of the feeds.

## Feeds

| File | What | Updated |
|---|---|---|
| [`youtube-channels.xml`](youtube-channels.xml) | Regular videos (no Shorts) from the YouTube channels the agent monitors | daily, 09:00 Europe/Ljubljana |

## Subscribing

Point a feed reader at the GitHub Pages URL:

```
https://zlatkoc.github.io/feeds/<file>.xml
```

For example: <https://zlatkoc.github.io/feeds/youtube-channels.xml>.

## Notes

- Don't edit the feed files by hand: they are regenerated from the agent's own data and
  any manual change is overwritten on the next run.
- Commits are made by the agent (`Hermes Agent (gooshie)`); edits to this README are fine.
